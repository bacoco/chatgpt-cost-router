# Token / Quota Economics

## Rough target
- conservative saving: ~50%
- central target: ~65–70%
- strong-fit months: ~80%+

These are workflow-displacement estimates, not billing telemetry.

## Savings mechanisms
1. Task displacement: tasks never reach Work/Codex.
2. Context compression: Chat hands Codex a compact task packet instead of making it rediscover the problem.

Potential delegated-task context reduction: ~20–50% in favorable cases.

## Measure
Track route, task class, escalations, handoff size, files touched, CI iterations, completion quality, retries, and observable usage snapshots.
