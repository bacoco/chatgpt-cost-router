# Routing Specification

## Mandatory rule
Do not recommend Codex/Work merely because a task contains code.

## CHAT
Prefer for research, synthesis, GitHub issues/PR/review, targeted edits, small/medium coding, data analysis, Gmail/apps.

## SCHEDULED_CHAT
Prefer for monitoring, recurring research, newsletters, delta T-1 -> T, periodic state updates.

## LOCAL_TOOL
Prefer owned hardware for inference, image/video, deterministic compute, benchmarks.

## CODEX
Escalate for deep repo traversal, long edit/test loops, large refactors, persistent dev environments.

## WORK
Escalate for interactive browser/computer use, UI-only workflows, complex desktop/local-app interaction, true long-running agentic execution.

## EXTERNAL_API
Use when a programmable metered backend/SLA is actually required.

## De-escalation
Return from Codex/Work to Chat when remaining work is research, synthesis, documentation, communication, routine GitHub or supported data processing.
