# ChatGPT Cost & Capability Router

Goal: maximize work performed in standard ChatGPT / Scheduled Tasks and minimize use of Work/Codex agentic quota.

## Strategy
1. Chat first.
2. Scheduled Chat for recurring automation.
3. Owned/local compute via MCP before paid agentic escalation.
4. Codex/Work only when a capability is genuinely missing.
5. Metered API last.

Central target: ~65–70% reduction in Work/Codex usage, to be measured rather than assumed.
